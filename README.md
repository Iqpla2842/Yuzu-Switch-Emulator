## Quickstart
1. **Download yuzu** — zip above (v1820).
2. Extract anywhere.
3. Put `prod.keys` in `%AppData%\yuzu\keys\`
4. Install **yuzu firmware**: Emulation → Configure → System
5. Add .nsp / .xci via File → Add New Game Directory

Dump keys from a Switch you own. Sharing firmware or ROMs you do not own is illegal.



## Android / iOS
Yuzu itself is desktop. Phones use forks: **Eden** (most active apk), Sudachi (stable), Citron (iOS via AltStore), Suyu (community).

## FAQ

**Yuzu vs Ryujinx?**
Both run most titles well. Keep both and pick per game. Eden is the usual Android pick.

**Keys mismatch?**
Keys version must match firmware or games fail to boot.

**Yuzu emulator 2026?**
This repo tracks community builds of the Yuzu codebase.
